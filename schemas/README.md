# Schemas

This directory contains draft JSON Schema contracts shared by the framework and REEF.

- `project.schema.json` describes estimate inputs.
- `estimate.schema.json` describes model outputs in PH.
- `actuals.schema.json` describes observed human effort.

The schemas use JSON Schema Draft 2020-12 and are pre-1.0. Breaking changes are expected. YAML documents are valid inputs when their parsed data conforms to the corresponding JSON Schema.
