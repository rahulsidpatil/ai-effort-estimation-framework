# Research

This area separates testable claims and evaluation artifacts from normative framework documentation.

- [`hypotheses/`](hypotheses/README.md) contains falsifiable proposals.
- [`experiments/`](experiments/README.md) contains reproducible study definitions and results.
- [`evaluation-protocols/`](evaluation-protocols/baseline.md) defines comparison procedures.

Merged research material does not imply scientific acceptance. State evidence quality and limitations explicitly.
