# Security Policy

## Supported versions

This project is pre-release and does not yet provide security-supported versions. Once releases begin, this section will list support windows.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository. If that feature is unavailable, contact the repository owner privately through their GitHub profile and request a secure reporting channel; do not include sensitive details in the initial message.

Include the affected component or version, reproduction conditions, impact, and any suggested mitigation. You should receive an acknowledgement within seven days. Timelines for validation and remediation will depend on severity and maintainer availability.

## Data safety

REEF may eventually process operational delivery data. Do not commit production telemetry, credentials, personal data, confidential prompts, source code from third parties, or client-specific records. Security reports should use the minimum data necessary to reproduce the issue.

The initial containerized web POC is intended for local or controlled evaluation. It must not be represented as suitable for internet exposure, multi-tenant use, enterprise identity, or regulated data until those capabilities receive explicit design, implementation, and security review.
